# NoA 中英术语表 / Chinese-English Glossary

用于 newNoA 英文翻译。原则：
- 东方 Project 专有名词采用官方英文拼写（Touhou Wiki 惯例）。
- HOI4 游戏机制采用原版英文术语。
- 保持 `§Y...§!`、`£icon`、`$KEY$`、`\n`、`[Scope.GetName]` 等代码原样不动。
- 不确定的条目标注 ⚠，翻译时再确认。
- RoA English Translation mod 机翻严重、无校对，仅可用于核对 key 名，不得作为译文参考。
- 优先参照 key 名中隐含的英文命名（如 `tsukumo_arms_co_ltd_idea` → Tsukumo Arms Co., Ltd.）。
